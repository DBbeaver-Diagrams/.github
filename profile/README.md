## Core DBeaver Features

- **A Named Connection:** Save a connection only for a server and account that are yours.
- **A Schema You Can Read:** Open the database you expect and look at tables before you run a statement that changes rows.
- **SELECT First:** A query that only reads is how you see the data. UPDATE and DELETE come after you have seen the rows and you have a backup if they matter.
- **No Stored Password on a Shared PC:** A saved login on a computer other people use is their access as well as yours.

---

## About DBeaver

DBeaver is a desktop client for databases you are allowed to administer. A local development database, or a host where you were given an account, is the setting. It does not discover servers on a network for you to try, and a connection string you found in a file is not permission to log in.

The dangerous buttons are the ones that write. Read the SQL before you run it. A DELETE without a WHERE, or with the wrong WHERE, removes rows for real. Take a dump or work on a copy before you practice. Disconnect when the task is done. An open session is still authenticated.

If the account cannot see a database, that is the permission model. Do not switch to a more powerful user you were not given so the tree looks fuller.

## Tool Benefits

- **One Window for a Known Database:** You browse tables without inventing a host.
- **A Read Before a Write:** SELECT shows the rows you might change.
- **A Session You Can Close:** Disconnecting ends the login from this PC.

| **Account** | Yours, with limited rights if possible | A backup before deletes |

## Getting Started with DBeaver

Prerequisites: A database you may use, and the host, port, and user you were actually given.

1. **New Connection:** Enter that host. Do not scan for others.
2. **Open the Right Database:** Confirm the name before you run SQL.
3. **SELECT a Few Rows:** Read them. Then decide whether a change is even needed.
4. **Disconnect:** Do not leave the password stored on a shared Windows account.

## Professional & Personal Use Cases

- **A Local App Database:** Inspect tables your own software created.
- **A Careful Fix:** Update a row you have already selected and backed up.
- **A Shared Office Server:** Use the account the team issued, and stop if it cannot see the data.
- **A Handover:** Remove saved connections before the PC goes to someone else.
